甜心烘焙智能蛋糕商城：项目文件架构
====================================

本文件描述当前实际代码，而不是未来规划。系统由 FastAPI 后端、Vue 3 前端和配置驱动的单 Agent 组成。

项目根目录
----------

samrt_cake_store/
├── .env.example                    环境变量模板，不包含真实密钥
├── .gitignore                      运行数据、密钥、依赖与构建产物排除规则
├── cake_store.sql                  MySQL 基础结构与数据
├── migration_goods_detail.sql      商品详情字段增量迁移
├── 异常检测系统.command             macOS 前后端一键启动脚本
├── fastapi-app/                    FastAPI 后端
└── vue/                            Vue 3 + Vite 前端

依赖方向
--------

1. main.py → api、common、settings
2. api → agents、common、models
3. agents/agent → LangChain Core、config、schema
4. agents/factory → LangChain create_agent、model、knowledge、tools
5. agents/tools 与 agents/knowledge/index_tasks → models
6. Vue → HTTP API；前端不依赖后端内部模块

业务回答的数据链路为：API 鉴权 → grounding 结合多轮上下文确定性取证 → LangChain Agent 推理/可选工具调用 → MySQL 商品事实校验 → SSE 最终回答。

禁止 agents 核心执行器导入 FastAPI 路由。禁止恢复旧 services 智能目录或在 api/__init__.py 中放置接口业务。

运行时数据
----------

- fastapi-app/.env：本地密钥和连接参数，不提交 Git
- fastapi-app/chroma_db/：可重建向量索引，不提交 Git
- fastapi-app/files/：上传文件，不提交 Git
- node_modules/、dist/、__pycache__/：依赖或生成物，不提交 Git

验证命令
--------

后端：
PYTHONPATH=fastapi-app python3 -m unittest discover -s fastapi-app/tests -v

前端：
cd vue && npm run build

开发启动：
./异常检测系统.command
